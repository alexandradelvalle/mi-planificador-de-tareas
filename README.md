## 💡 Sobre el proyecto

**Planificador de Tareas** es una aplicación web que busca ofrecer un espacio personal para organizar actividades, gestionar pendientes y adaptar la planificación a las necesidades de cada usuario.

La idea parte de una premisa: cada persona tiene sus propios gustos, prioridades y maneras de organizarse. Por eso, el objetivo es construir una herramienta funcional, intuitiva y personalizable, donde cada usuario pueda trasladar su mundo a la organización de su día a día.

> Organiza tu vida a tu manera. Haz de este espacio algo tuyo.

## ⭐ Objetivos

- Crear una aplicación web para planificar y gestionar tareas.
- Facilitar el registro y la organización de actividades.
- Diseñar una interfaz intuitiva, agradable y adaptable a diferentes usuarios.
- Incorporar progresivamente opciones de personalización.
- Aplicar los conocimientos adquiridos durante el bootcamp de desarrollo Full Stack.

## 🔎 Funcionalidades

Las funcionalidades se desarrollarán progresivamente durante los diferentes sprints del proyecto.

### Sprint 1 · Interfaz inicial

- ✅ Construcción de la estructura principal de la interfaz con formulario para registrar tareas.
- [ ] Componente visual para representar cada tarea.
- [ ] Validación de los datos del formulario.

### Próximas etapas

- [ ] Implementación de operaciones CRUD.
- [ ] Consumo e integración de APIs.
- [ ] Desarrollo del backend y conexión con el frontend.
- [ ] Persistencia de datos mediante una base de datos SQL.
- [ ] Opciones de personalización del espacio.

*Esta lista se actualizará a medida que avance el desarrollo.*

## 💻 Tecnologías

Las tecnologías se incorporarán según los objetivos de cada sprint.

| Tecnología | Uso previsto |

| HTML5 | Estructura de la interfaz |
| CSS3 | Estilos y presentación visual |
| Bootstrap 5.3 | Diseño y componentes de interfaz |
| JavaScript | Interactividad y manipulación del DOM |
| Java | Desarrollo del backend |
| Spring Boot | Construcción de la aplicación del servidor |
